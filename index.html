daffin

Tous les jeux de la maison dans une seule bibliothèque. Sur Android, l'application vous prévient quand une nouvelle version est prête : vous choisissez de l'installer.

Télécharger daffin pour Android

Ouvrez le fichier téléchargé pour l'installer. La première fois, Android demande d'autoriser votre navigateur à installer des applications : autorisez-le, puis revenez au fichier.

daffin pour Linux

Sur un ordinateur sous Linux, pour jouer aux jeux d'une autre machine ou partager les siens. L'application vous prévient quand une nouvelle version est prête : vous choisissez de l'installer, et votre système demande le mot de passe administrateur.

Debian, Ubuntu (.deb)Fedora (.rpm)

daffin pour Windows

Sur un PC sous Windows 10 ou 11, pour jouer aux jeux d'une autre machine ou partager les siens. L'installation ne demande pas de mot de passe administrateur, et l'application vous prévient quand une nouvelle version est prête : vous choisissez de l'installer.

Windows 10 et 11 (.exe)

L'installeur n'est pas signé : à chaque nouvelle version téléchargée ici, Windows affiche « Windows a protégé votre ordinateur ». Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Pour vérifier le fichier, comparez son SHA-256 avec celui du fichier SHA256SUMS de la version.
